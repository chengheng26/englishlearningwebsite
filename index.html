学习设置与数据

这是一个静态网站，不需要注册账号。词库数据只保存在当前浏览器的本地存储中。

重要：GitHub Pages 负责发布网页，不会自动同步你的个人词库到其他设备。更换浏览器或手机前，请使用「导出备份」，在新设备打开网站后再「导入备份」。

建议的学习流程

  1. 每天添加 5–10 个单词或句子。
  2. 听英式发音，先尝试听出重音和词尾。
  3. 为重要单词补充中文意思和自己的例句。
  4. 勾选今天想练的内容，开始听写。
  5. 每周导出一次 JSON 备份。

语音与隐私

语音合成通常由浏览器或设备完成。查询词典时，输入的单词会发送给公开词典 API；本网页本身没有账号系统，也不会把词库上传到你的 GitHub 仓库。
